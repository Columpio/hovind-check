# Формат данных

- `lectures/lectures.yaml` — список лекций: `slug`, `number`, `title`, `kind` (`film` для «Ложи во имя науки»), `author`, `source`, `voiceover`, `rights`, `youtube {id, channel, offset}`, `rutube {id, channel, offset | offsets}`, `draft`. Время в разметке — по локальному файлу (совпадает с YouTube-загрузкой). `offset` в секундах: время на площадке = время лекции + offset. Если копия смонтирована иначе, вместо `offset` — `offsets: [{from, offset}]`: действует последний пункт с `from` ≤ время лекции.
- `lectures/<slug>/claims.yaml` — утверждения: `id`, `start`, `end` (секунды), `text` (полный текст отрезка без «…»; заполняет `python scripts/fill-claim-text.py` из расшифровки в `resources/`), `rating` (`green|neutral|orange|red|purple`), `verdict` (1–2 фразы), `arguments: [slug]` (не больше одного), `rhetoric: [slug]`. Своего текста «Подробнее» у утверждения нет: там только вставки статей довода и приёмов.
- `tags.yaml` — словарь всех меток: секции `arguments` и `rhetoric`, у каждой метки `slug`, `title`, `summary` (одна фраза сути), для богословских — `theology: true`. Каждая метка из `claims.yaml` и каждая статья должны быть здесь. Новую метку сначала добавляем сюда.
- `arguments/<slug>.md`, `rhetoric/<slug>.md` — статьи каталогов. Frontmatter: `title`, `summary`; тело — markdown. Статья необязательна: пока её нет, на сайте показываются `title` и `summary` из `tags.yaml` и пометка «разбор готовится». Если статья есть, её frontmatter важнее словаря.
- Два нейтральных утверждения не идут подряд: соседние нейтральные куски объединяем в одно (start первого, end последнего, общий вердикт).
- Ошибки разметки (в том числе нейтральные подряд, неизвестные метки, повтор id) останавливают `npm run build`; та же проверка идёт перед `git push` (хук ставится командой `npm run hooks`) и в GitHub Actions.
- `feedback.yaml` — форма для замечаний читателей: `formId` (часть ссылки `docs.google.com/forms/d/e/<formId>/viewform`) и `entries` — номера полей формы `entry.NNN` для `quote` (выделенный текст), `link` (ссылка на место, с `#t=…` утверждения) и, по желанию, `page` (заголовок страницы; в нашей форме этого поля нет). Номера берутся из «предварительно заполненной ссылки». Пока `formId: TODO`, кнопки замечаний на сайте нет.
- Частоты и связи «довод ↔ приём» считаются при сборке по меткам в `claims.yaml`.
