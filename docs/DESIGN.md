# DESIGN.md — визуальное направление

## Направление: «Тихая сверка»

Сайт похож не на журнал и не на «разоблачение», а на спокойную рабочую тетрадь: слева звучит лекция, справа — карточки, где каждое утверждение сверено и помечено. Читатель — простой верующий, часто с телефона, иногда пожилой. Поэтому:

- **крупно и контрастно**: основной текст 19px, межстрочный 1.6, контраст не ниже 4.5:1 (WCAG AA) в обеих темах;
- **ничего «атеистического» или агрессивного**: нет чёрного фона по умолчанию, неоновых акцентов, насмешливых иллюстраций; красный только у оценки «неверно»;
- **понятные подписи**: у кнопок есть текст («К текущему моменту», «Развернуть всё»), иконки только дополняют. Исключение — якорь-ссылка у карточки (иконка цепи с подсказкой, как в Википедии);
- **оценка не только цветом**: у каждой оценки своя иконка (галочка, черта, треугольник, крестик, книга) и подпись.

**Фирменный элемент** — цветная полоса слева у карточки утверждения: по колонке карточек сразу видно, где Ховинд прав, где ошибается, а где спорный богословский вопрос. Остальное оформление сдержанное.

Оценки (текст / фон плашки), светлая тема: зелёный `#2e7d32`/`#e8f3e9`, нейтральный `#6b7280`/`#f1f2f4`, оранжевый `#b45309`/`#fdf1e3`, красный `#b91c1c`/`#fbeaea`, фиолетовый `#6d28d9`/`#f1eafd`. В тёмной теме — светлые варианты тех же оттенков (см. `src/styles/global.css`).

## Шрифты (кириллица)

- **Текст** (цитаты, разборы, статьи): **Literata** — шрифт для длинного чтения с экрана, хорошая кириллица, вариативный.
- **Интерфейс и заголовки**: **Golos Text** — гротеск, разработан для русскоязычных госсервисов, очень читаемый на телефоне.
- Подключаем локально через `@fontsource-variable/*` (без запросов к Google Fonts: быстрее в России и без передачи данных третьим лицам).

База ui-ux-pro-max для «образовательного контента» предложила Crimson Pro + Atkinson Hyperlegible, но у Atkinson нет кириллицы; заменили на пару с полной кириллицей тех же свойств (книжный текст + максимально разборчивый интерфейс).

## Компоновка

- **Компьютер**: слева узкий липкий «пульт» 320–400px (видео + оценки-фильтр с пояснениями + «развернуть/свернуть»), справа широкий разбор до 780px. Пустой колонки под видео нет.
- **Телефон**: прилипает только плеер; его высота не больше 38% экрана (и в альбомной ориентации), кнопкой «Свернуть» он сжимается до полосы с кнопками. Оценки — одна строка с прокруткой вбок, легенда по «Что значат цвета?».
- **Карточка утверждения**: одна фирменная полоса оценки слева; цитата («Ховинд говорит») и «Наш разбор» разделены линией; без лишних рамок и цветных плашек. Тап по тексту ничего не прячет.
- **Что видно всегда**: цитата («Ховинд говорит») и «Наш разбор» (вердикт 1–2 фразы). Их не сворачивают ни стрелка, ни «Свернуть всё».
- **Внизу карточки** — кнопка-«кат» по всей ширине «Почему так ⌄» / «Скрыть объяснение ⌃» (подписи этапа 9), в том же стиле, что у вставок. Отдельной стрелки сворачивания в углу нет. «Развернуть всё / Свернуть всё» раскрывают и сворачивают только подробности.
- **«Почему так»** раскрывает только блоки-вставки: один повторяющийся довод и риторические приёмы, без своего текста, и маленькую ссылку «Написать замечание к этому месту». Если вставок нет, кнопки тоже нет. Каждый блок — это одинаковая раскрывающаяся вставка: заголовок с подписью («Довод Ховинда, он его часто повторяет» / «Приём в споре») и кратким описанием, по раскрытию — полный текст статьи. Ссылка «Где ещё Ховинд это говорит →» / «Где ещё встречается этот приём →» внутри, а не вместо вставки. Внизу заголовка вставки — явная кнопка-«кат» по всей ширине с пунктирной чертой: «Весь разбор ⌄» (или «Разбор готовится ⌄», если статьи ещё нет), после раскрытия — «Свернуть ⌃». Читатель должен сразу видеть, что блок раскрывается.
- **Статьи ещё нет** (метка есть только в `data/tags.yaml`): вставка выглядит так же, а по раскрытию вместо текста — приглушённая строка «Подробный разбор этого довода/приёма готовится…» и та же ссылка. В каталоге у такой метки серая плашка «разбор готовится»; её страница показывает суть, эту строку, связанные метки и список мест. Метки без статьи, которые не встречаются в разметке, в каталог не попадают.
- Внизу лекции — «предыдущая / следующая / все лекции».
- Текстовые страницы (статьи, каталоги, «О проекте», главная) — колонка до 880px по центру экрана.
- Шкала размеров от 19px (`html { font-size: 19px }`): rem = основной текст, подписи не мельче 0.72rem (~14px).
- Все касаемые цели ≥ 44px (`--tap`).
- Цвет оценки — классом `r-<оценка>` (переменные `--c`/`--cbg`), а не отдельными правилами в каждом компоненте.

## Что ожидает пользователь (реализовано в скелете)

- тайм-код у каждого утверждения: клик — видео с этого места; адрес `#t=12m34s` открывает страницу на этом утверждении;
- якорь у каждого утверждения (иконка цепи в правом верхнем углу), как в Википедии: клик меняет адрес на `#t=…`, прокручивает карточку наверх и ставит видео на этот момент; ссылку копируют из адресной строки или правой кнопкой по якорю. Отдельной кнопки «Скопировать ссылку» нет;
- «К текущему моменту» — прокрутить разбор к тому, что сейчас звучит; звучащее утверждение подсвечено рамкой;
- фильтр по оценкам (кнопки-легенда с количеством), «Развернуть всё / Свернуть всё» (только подробности);
- переключатель YouTube / RuTube (выбор запоминается);
- навигация «предыдущая / следующая лекция», кнопка «Наверх», поиск в каталогах;
- доступность: ссылка «Перейти к содержанию», видимый фокус, `aria-pressed` у переключателей, `aria-current` у звучащего утверждения, касаемые цели ≥ 36–44px, `prefers-reduced-motion`;
- тёмная тема: по системной настройке, переключатель в шапке.

## Страница статьи: видео и связи

- **«Послушайте также наш разбор»** — после текста статьи: карточки фрагментов наших видео (поле `videos` во frontmatter: `id`, `t`, `title`, `note`). Превью с плашкой «▶ с 12:34» — лёгкий фасад: плеер YouTube (youtube-nocookie, `start=t`) грузится только по клику, на телефоне карточка в одну колонку. Внизу — ссылки на канал и на цикл «Библия и культура Древнего Востока».
- **«Похожие доводы / приёмы»** — до 6 чипов, считаются при сборке: соседство меток в лекциях (то же или ±2 утверждения) плюс ссылки из текста статьи (вес 3).
- **«На этот разбор ссылаются»** — статьи, в тексте которых есть ссылка на эту (до 6); у статей другого каталога подпись «· довод» / «· приём».

## Обратная связь

- Замечания читателей и коллег идут в предзаполненную Google Форму (`data/feedback.yaml`), сайт ничего не хранит. Пока форма не настроена, этих элементов на сайте нет.
- **Выделил — отправил:** при выделении текста в основной части страницы **под** выделением (не над ним: там системное меню телефона) появляется кнопка-пилюля «Замечание к этому месту» (акцентная рамка, высота 44px). Клик открывает форму в новой вкладке с цитатой, ссылкой на утверждение (`#t=…`) или страницу и заголовком. Esc прячет кнопку.
- Постоянная ссылка «Нашли ошибку или есть замечание? Напишите нам» — в футере; на странице лекции под плеером тихая подсказка «Выделите текст, чтобы отправить замечание».

## Правила

- Цвета только через токены из `global.css`, без «сырых» hex в компонентах.
- Иконки — SVG, не эмодзи.
- Анимации 150–300 мс, только для смысла (раскрытие, подсветка), с учётом reduced-motion.
