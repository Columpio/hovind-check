# Семинар Ховинда: проверка фактов

Подробный разбор лекций Кента Ховинда («Семинар о сотворении») и фильма «Ложь во имя науки» с точки зрения современной науки. Каждое утверждение показано с тайм-кодом и видео, оценено и прокомментировано простым языком со ссылками на источники.

Проект делают христиане разных деноминаций. Мы не спорим с верой в Бога-Творца, а проверяем научные утверждения.
